# NPL Auction — Phase 1 Scaffold

This repository contains the initial scaffold for the IIIT Nagpur Premier League (NPL) Auction System.

Phases and checklist are tracked in the project root checklist.

Quick start (backend):

- Edit `backend/.env` (or copy from `.env.example`) and set `MONGO_URI` and `PORT`.
- Install dependencies in `backend/` with `npm install`.
- Run backend with `npm run dev` (if using nodemon) or `node server.js`.

Frontend:

- Use `create-react-app` or `vite` inside `frontend/` to scaffold the React app.
- Install `socket.io-client` and `axios` (or use fetch).

See checklist.md for the full Phase 1 requirements.
